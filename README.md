# PashuRaksha AI – Smart Livestock Disease Management & Early Warning System
**Smart India Hackathon 2026 • Problem Statement 26128**

An AI-powered early livestock disease-risk detection, automatic veterinary escalation, and community-level outbreak early warning system tailored for rural India, low-connectivity zones, and non-smartphone users.

---

## 📌 Problem Statements Solved
- **Late Detection of Livestock Diseases**: Preventable cattle mortality due to delayed disease identification.
- **Limited Access to Veterinarians**: Only 1 vet per 5,000+ livestock across rural Indian districts.
- **Scattered Health Records**: Lack of centralized animal registration, vaccination schedules, and clinical histories.
- **Missing Outbreak Detection**: Inability to cluster localized disease flare-ups at the village level before they cross taluka boundaries.
- **Poor Internet Connectivity**: Offline-first architecture stores and syncs reports seamlessly via IndexedDB/LocalCache.
- **Limited Smartphone Access**: Interactive Voice Response (IVR) helpline for basic feature phones.

---

## 🏛️ Core Workflow Architecture
```
Farmer → Health Report → AI Multimodal Risk Engine → Risk Score (0-100) → Automatic Vet Escalation → Lab Referral → Treatment & Follow-up → Community Outbreak Engine → Early Warning Broadcast
```

---

## 🚀 Technology Stack
- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide React, Motion, Leaflet / OpenStreetMap.
- **Full-Stack Node/Express Gateway**: Port 3000 hosting live REST endpoints and Vite middleware.
- **Python FastAPI Reference Backend**: In `/backend` directory with FastAPI, Pydantic, and scikit-learn models.
- **AI Risk Engine**: Multimodal scoring engine combining body temperature abnormalities, clinical symptoms, computer vision epidermal findings, vaccination status, and environmental vectors.
- **Maps**: Leaflet + OpenStreetMap displaying risk markers (🟢 Low, 🟠 Medium, 🔴 High) and cluster warning circles.
- **Offline Sync**: Automatic connection listener and pending report synchronization queue (`POST /api/sync`).
- **IVR Telephony**: Toll-free Kisan voice simulator with speech synthesis and Twilio/Exotel webhook adapter.
- **Multilingual UI**: English, Hindi (हिंदी), and Marathi (मराठी).

## ⚡ Quick Start & Running the Project

### Running Full-Stack Dev Server (Node/Express + React Vite):
```bash
npm install
npm run dev
```
The application will launch on `http://localhost:3000`.

### Running Python FastAPI Backend (Optional alternative):
```bash
cd backend
pip install -r requirements.txt
python main.py
```
FastAPI interactive Swagger documentation available at `http://localhost:8000/docs`.

## ⚖️ Ethical AI & Medical Disclaimer
Predictions generated by PashuRaksha AI represent assistive **computational screening and risk estimation only**. The system never claims definitive veterinary diagnosis; all high-risk screenings mandate physical examination by a registered veterinary practitioner.
